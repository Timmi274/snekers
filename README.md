# snekers · AMVER

Копия лендинга и каталога [amver-sneakers.lovable.app](https://amver-sneakers.lovable.app/),
собранная на Next.js (App Router) + Tailwind CSS v4. Все изображения заменены на
официальные продуктовые фото моделей с сайтов производителей и их CDN
(Nike, adidas, New Balance, ASICS, Salomon) и лежат локально в `public/products`.

## Страницы

- `/` — главная: герой-блок со статистикой и бестселлером недели, категории,
  популярные модели, «Почему AMVER», отзывы, FAQ;
- `/catalog` — каталог: поиск, сортировка, фильтры по бренду / категории / размеру,
  поддержка `?category=` из карточек категорий;
- `/product/[slug]` — карточка товара: размеры (EU), «Заказать» / «В корзину»,
  описание, похожие модели;
- `/cart` — корзина (localStorage) с итогом и порогом бесплатной доставки от 15 000 ₽.

## Данные

Каталог из 12 моделей — в `src/lib/catalog.ts` (цены, размеры, рейтинги, бейджи и
описания совпадают с оригинальным сайтом).

## Запуск

```bash
npm install
npm run dev   # http://localhost:3000
```
